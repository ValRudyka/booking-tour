Порядок роботи: спочатку план на затвердження, код лише після мого «ок».

Спільні правила — як у `docs/frontend/01-catalog-page.md`, розділи 1–2. Зараз `/` перенаправляє на `/tours`; ця сторінка замінює перенаправлення.

## 0. Що прочитати перед планом

1. `docs/tz/TZ_tour_website_v2.md`: головна сторінка, публічна інформація для гостя.

У плані окремо: що з розділу 2 можна зробити на наявному API, а що потребує нового ендпоінту. Нові ендпоінти не додавати без мого рішення.

## 2. Блоки

### Банер із пошуком
- `<h1>` і один рядок підзаголовка (тексти через i18n; у плані запропонувати 2–3 варіанти заголовка на мій вибір).
- Форма пошуку: країна, дати (`RangePicker`), місто вильоту, кнопка «Знайти тури» (primary).
- Кнопка переводить на `/tours` з тими самими параметрами в URL, які вже розуміє каталог (назви параметрів API). Порожня форма — просто `/tours`.
- Без фото-банерів і каруселей (немає власних фото; без анімацій).

### Найближчі виїзди
- 4 тури з найближчою датою виїзду (`date_asc`), опубліковані й з вільними місцями — тим самим запитом каталогу.
- Ті самі `TourCard`. Сітка 4 → 2 → 1.
- Посилання «Усі тури» на `/tours`.

### Популярні напрямки
- Країни з довідника як `Card` або кнопки з назвою (без прапорів-емодзі; без картинок, поки їх немає). Клік — `/tours?country_id=…`.
- Якщо API може повернути кількість турів за країною — показати «12 турів»; якщо ні — без числа.

### Як забронювати
- 4 кроки статичним текстом з іконками `@ant-design/icons` (`SearchOutlined`, `FormOutlined`, `CreditCardOutlined`, `FileDoneOutlined`).

### Відгуки туристів
- Лише якщо є загальний список опублікованих відгуків. 3 останні: оцінка, короткий уривок, назва туру з посиланням.
- Якщо такого ендпоінту немає — блок не робити і написати про це в плані.

## 3. Інше

- `document.title` = `SITE_NAME`; мета-опис сторінки (`<meta name="description">`) через `index.html` або хелпер.
- Помилка в одному блоці (наприклад, відгуки) не ламає решту сторінки.
- Завантаження: `Skeleton` у кожному блоці окремо, `active={false}`.

## 4. Тести (у тих самих комітах, що й код)

- Пошук переводить на `/tours` з правильними параметрами; порожня форма — на `/tours`.
- Блок найближчих виїздів показує картки з мок-даних і посилання на всі тури.
- Клік по напрямку відкриває каталог із фільтром країни.
- Помилка відгуків не ламає сторінку.
