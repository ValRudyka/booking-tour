## 1. Стек

| Що | Чим |
|---|---|
| Збірка | Vite + React 19 + TypeScript (strict) |
| UI | antd 6 + @ant-design/icons 6 (версії мають збігатися). Без Tailwind, без ProComponents у цій гілці |
| Маршрути | React Router |
| Дані з API | TanStack Query + axios |
| Типи API | Генеруються з `/openapi.json` бекенду через openapi-typescript (npm-скрипт `gen:api`) |
| Тексти | react-i18next: поки лише українська, але всі тексти інтерфейсу йдуть через ключі |
| Тести | Vitest + React Testing Library |

Фронтенд розміщується в папці `frontend/` цього репозиторію.

## 2. Дизайн

- Тема antd через `ConfigProvider`, локаль `uk_UA`:

```tsx
theme={{
  token: {
    colorPrimary: '#0E7490',
    colorSuccess: '#15803D',
    colorWarning: '#B45309',
    colorError: '#B91C1C',
    colorTextBase: '#0F172A',
    colorBgLayout: '#F8FAFC',
    borderRadius: 6,
    motion: false,
  },
}}
```

- `src/theme.ts`: `PRICE_COLOR = '#C2410C'` (лише для цін і знижок, ніколи для кнопок) і `SAND_BG = '#F2E8D5'` (лише для великих фонових блоків).
- Жодних анімацій (`motion: false`; у `Skeleton` прописати `active={false}`).
- Жодних емодзі в інтерфейсі. Іконки беруться лише з `@ant-design/icons`.
- Контраст тексту не нижче 4.5:1. Кожне поле фільтра має видимий підпис (`label`), а не лише placeholder. Усе має працювати з клавіатури.

## 3. Фундамент (одноразово для всього фронтенду)

```
frontend/
  src/
    api/          axios-клієнт, згенеровані типи, хуки запитів
    components/   TourCard, спільні компоненти
    layouts/      PublicLayout
    pages/        CatalogPage, TourDetailsPlaceholder, NotFoundPage
    i18n/         налаштування, uk.json
    theme.ts
    App.tsx, main.tsx, router.tsx
  .env.example    VITE_API_URL=http://localhost:8000
```

- **axios**: `baseURL` береться з `VITE_API_URL`. Помилки API зводяться до одного формату, щоб сторінки показували зрозуміле повідомлення.
- **TanStack Query**: один `QueryClient`, розумні `staleTime` і `retry` (на помилках 4xx повтор не потрібен).
- **PublicLayout** (antd `Layout`):
  - шапка: назва сайту (поки константа `SITE_NAME`), посилання «Тури» і «Про нас», кнопки «Увійти» та «Реєстрація», які поки ведуть на заглушки;
  - контент на ширину до 1200 px по центру;
  - футер: контакти, «Умови», «Політика конфіденційності»;
  - на мобільному меню шапки ховається в `Drawer`.
- **Маршрути**: `/` перенаправляє на `/tours` (поки немає головної), `/tours`, `/tours/:id` (заглушка), `*` показує 404 через antd `Result` з кнопкою «До каталогу».
- **CORS**: перевірити, що бекенд дозволяє `http://localhost:5173`. Якщо ні, це окремий невеликий коміт у бекенді з тестом.

## 4. Сторінка каталогу `/tours`

### Розмітка

```
┌──────────────────────────────────────────────────────────┐
│ Шапка                                                    │
├───────────────┬──────────────────────────────────────────┤
│ Фільтри       │ Знайдено N турів        Сортування ▾     │
│ (Card, ліва   │ ┌────────┐ ┌────────┐ ┌────────┐         │
│  колонка      │ │TourCard│ │TourCard│ │TourCard│         │
│  ~280 px)     │ └────────┘ └────────┘ └────────┘         │
│               │ ...                                      │
│ [Застосувати] │              ‹ 1 2 3 ›                   │
│ [Скинути]     │                                          │
├───────────────┴──────────────────────────────────────────┤
│ Футер                                                    │
└──────────────────────────────────────────────────────────┘
```

- Десктоп: фільтри в лівій колонці, картки в сітці по 3 (antd `Row`/`Col`, адаптивно: 3, потім 2, потім 1).
- Мобільний: кнопка «Фільтри» відкриває `Drawer`, картки йдуть в одну колонку.
- Заголовок сторінки `<h1>`: «Каталог турів». Також оновлюється `document.title`.

### Фільтри

Беремо з ТЗ, але лише ті, які підтримує API каталогу:

| Фільтр | Компонент antd | Звідки дані |
|---|---|---|
| Пошук за назвою | `Input.Search` | — |
| Країна | `Select` з пошуком | довідник країн |
| Курорт | `Select`, залежить від країни | довідник курортів |
| Місто вильоту | `Select` | довідник міст вильоту |
| Дати виїзду | `DatePicker.RangePicker` | — |
| Кількість ночей | `Slider` (range) або два `InputNumber` | — |
| Ціна, ₴ | два `InputNumber` (від/до) | — |
| Зірковість готелю | `Checkbox.Group` (3, 4, 5) | — |
| Харчування | `Checkbox.Group` (BB, HB, AI, UAI) | — |

Сортування: ціна (зростання / спадання), рейтинг готелю, найближча дата виїзду.

**У плані окремим списком: які фільтри з ТЗ API не підтримує.** Не імітувати фільтрацію на клієнті. Вирішимо, чи додавати їх у бекенд.

### Поведінка

- Усі фільтри, сортування й номер сторінки зберігаються в query-рядку URL (`?country=…&page=2`). Посилання з фільтрами можна відкрити в новій вкладці, а кнопка «Назад» працює.
- Зміна фільтра скидає сторінку на 1.
- Текстовий пошук із затримкою (debounce ~400 мс). Решта фільтрів застосовується одразу на десктопі, а в мобільному `Drawer` — кнопкою «Застосувати».
- «Скинути фільтри» очищає URL.
- Пагінація серверна, через параметри самого API. Розмір сторінки 12.
- Курорт скидається, коли змінюється країна.

### Картка туру `TourCard`

- Фото туру або готелю. Якщо фото немає, показується нейтральна заглушка з іконкою (без зовнішніх картинок).
- Назва туру (до 2 рядків з обрізанням).
- Країна, курорт · назва готелю та зірки (antd `Rate disabled` або іконки).
- Кількість ночей · найближча дата виїзду · місто вильоту.
- Рейтинг готелю (якщо є; якщо `null`, показується «Ще немає відгуків»).
- Тип харчування (`Tag`).
- Ціна «від N ₴» кольором `PRICE_COLOR`, з форматуванням через `Intl.NumberFormat('uk-UA')`.
- Якщо вільних місць мало (наприклад, 3 або менше), показується `Tag` «Залишилось N місць».
- Уся картка є посиланням на `/tours/:id` і доступна з клавіатури.

### Стани

| Стан | Що показати |
|---|---|
| Завантаження | 6 `Skeleton` у формі картки, `active={false}` |
| Порожній результат | antd `Empty`: «За вашими фільтрами турів не знайдено», кнопка «Скинути фільтри» |
| Помилка API | `Alert type="error"` зі зрозумілим текстом і кнопкою «Спробувати ще раз» |
| Режим обслуговування (якщо API повертає відповідний статус) | `Result` з поясненням |

## 5. Тести (у тих самих комітах, що й код)

- `TourCard`: показує ціну у форматі «від 32 000 ₴», рейтинг, заглушку без фото й «Ще немає відгуків», коли рейтинг `null`.
- Фільтри оновлюють query-рядок URL, а зміна фільтра скидає `page` на 1.
- Стани: порожній результат і помилка (з кнопкою повтору).
- Запити до API в тестах мокаються.
